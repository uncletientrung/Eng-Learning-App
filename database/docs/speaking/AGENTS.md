Đây là hệ thống đánh giá IELTS Speaking bằng trí tuệ nhân tạo.

2. Yêu cầu trước khi thực hiện công việc

Trước khi triển khai bất kỳ chức năng nào:

Đọc tài liệu liên quan đến chức năng được giao.
Hiểu kiến trúc hiện tại của hệ thống.
Kiểm tra source code liên quan.
Tuân thủ quy ước lập trình hiện có.
3. Quy tắc phát triển
Tuân thủ kiến trúc hiện tại.
Áp dụng SOLID khi phù hợp.
Không thêm thư viện không cần thiết.
Không chỉnh sửa những module không liên quan.
Không tạo chức năng trùng lặp.
Tuân thủ quy ước đặt tên database.
Xử lý lỗi một cách rõ ràng.
4. Quy tắc thực hiện task
Chỉ triển khai task được giao.
Không tự ý mở rộng phạm vi công việc.
Chạy các bài kiểm thử liên quan sau khi triển khai.
Báo cáo các file đã thay đổi và kết quả kiểm thử.
Cập nhật tài liệu khi cần thiết.
5. Quy tắc tiết kiệm token
Chỉ đọc những file liên quan đến task.
Không đọc lại tài liệu không thay đổi nếu không cần thiết.
Không xuất toàn bộ source code khi không cần.
Tóm tắt ngắn gọn các kết quả phân tích và quyết định kỹ thuật.
